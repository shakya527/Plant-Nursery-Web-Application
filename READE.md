# Plant Nursery Web Application

A comprehensive web-based management system designed for plant nurseries to streamline operations, manage inventory, and handle customer orders efficiently.

## Features
- **User Authentication:** Secure login and registration for users.
- **Plant Management (CRUD):** Add, view, edit, and delete plant records.
- **Customer Portal:** Catalog browsing, cart management, and order cancellation.
- **Dashboard:** Overview of sales, inventory, and system statistics.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL

## Setup Instructions
1. Clone the repository.
2. Import `database.sql` into your MySQL server via phpMyAdmin.
3. Place the project folder inside your local server directory (e.g., `C:/xampp/htdocs/`).
4. Access the application in your browser at `http://localhost/Plant-Nursery-Web-Application`.
