# 🪴 Plant Nursery Web Application

A modern, responsive, and secure web application built using PHP, MySQLi, and Bootstrap/CSS. This project provides plant nursery owners and admins with a streamline operations, inventory management, and customer ordering portal.

## 📝 Project Description
Plant Nursery Web Application provides a complete digital solution for managing nursery inventory, updating plant status, handling customer shopping carts, and processing orders efficiently through an intuitive dashboard and user interface.

## ✨ Features
- 🔐 **User Authentication:** Secure session-based login and registration system.
- 🪴 **Plant Management (CRUD):** Add, view, edit, and delete plant records with image support.
- 🛒 **Customer Portal:** Catalog browsing, shopping cart management, and online ordering.
- 📊 **Interactive Dashboard:** Overview of total stock, orders, and sales performance.
- 🗑️ **Safe Record Handling:** Validation checks for data integrity and error prevention.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap
- **Backend:** Native PHP 8.0+
- **Database:** MySQL 5.7+ / MariaDB 10.4+
- **Development Environment:** XAMPP, VS Code

## 💻 System Requirements
- **Web Server:** Apache (via XAMPP, WAMP, or LAMP)
- **PHP Version:** PHP 8.0 or newer (with mysqli and session extensions enabled)
- **Database:** MySQL 5.7+ or MariaDB 10.4+
- **Web Browser:** Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari

## 🚀 Installation Steps

1. **Download / Clone the Repository:** Place the project folder inside your web server's root directory:
   `C:\xampp\htdocs\Plant-Nursery-Web-Application`

2. **Start Local Server:** Open the XAMPP Control Panel and click **Start** for both Apache and MySQL.

3. **Database Setup (phpMyAdmin):**
   - Open your web browser and navigate to: `http://localhost/phpmyadmin`
   - Create a new database.
   - Click on the **Import** tab and select the `database.sql` file located in the project root.
   - Click **Go / Import**.

4. **Access Application:** Open `http://localhost/Plant-Nursery-Web-Application` in your browser.
